# پرامپت‌گالری — اسکلت اولیه پروژه

این پروژه با Next.js (App Router) + TypeScript + Tailwind CSS ساخته شده.

## شروع کار

```
npm install
npm run dev
```

بعد آدرس http://localhost:3000 رو تو مرورگر باز کن.

## قدم بعدی

این پروژه رو تو Claude Code باز کن و PRD (فایل PRD-گالری-پرامپت.md) رو بهش بده تا زمینه کامل پروژه رو داشته باشه.
از بخش ۱۶ چک‌لیست PRD پیروی کن: اول اتصال دیتابیس، بعد گرید گالری با دیتای فیک، بعد اتصال واقعی، بعد فیلتر و مودال.
